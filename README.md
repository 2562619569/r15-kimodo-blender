# R15 Kimodo：关键姿势 + 文本过渡

用于 Blender 5.x，依赖已启用的 Proscenium。沿用 Proscenium 的服务地址、登录信息和当前模型；已针对自托管 `kimodo-soma-rp` / SOMA30 实测。

## 使用

1. 在 Proscenium 连接 Kimodo 服务，选择模型。
2. 打开 3D 视图右侧 N 面板的 **R15 Kimodo**，选择 R15 角色。
3. 在不同帧摆好身体姿势，使用 Blender 的 I 插关键帧，或点 **记录当前全身姿势**。至少两个关键姿势。
4. 点 **读取关键帧**。插件会为每两个相邻姿势创建一个文本输入框；填写这段时间内希望发生的动作。
5. 点 **生成文本过渡**。后台逐段调用服务，界面显示进度。每段单独提交两个端点的全身约束，以保持关键姿势时间不受模型多文本重叠窗口影响。
6. 完成后自动切到生成的独立 Action。黄色关键帧是原始锚点，灰色帧是生成过渡。
7. 点 **返回关键姿势** 继续修改，重新读取关键帧后再生成。原始 Action 一直保留。
8. 选择生成结果后，沿用现有 Roblox Animations Importer/Exporter 导出流程。

英文动作描述通常更适合模型。文本直接交给服务，插件不翻译、不替换。关键姿势决定端点，文本决定过渡动作。

## 范围

- 标准 R15 身体名称和父子结构，包括 HumanoidRootPart 与 15 个身体部位。
- 自动校准角色朝向、初始手臂姿态、骨轴与腿长比例。
- R15 → SOMA 姿势约束 → Kimodo → R15，全身姿势在锚点处保留。
- 按时间换算场景帧率与模型帧率，原有帧号和时长不变。
- 可调过渡平滑（默认 0.08 秒），平滑后再约束回原始关键姿势。
- 保留身体以外的面部、附件曲线及 Roblox 关节元数据。
- 根移动通过骨盆姿态写回，并保留原始 HumanoidRootPart 曲线；这是骨架动画，不会创建 Roblox 游戏角色的移动脚本。
- 身体骨骼上的活动约束、NLA 混合、缩放关键帧不在当前输入范围；遇到这些输入会明确报错，需先烘焙/关闭 NLA。
- 使用服务声明的时长、文本及约束上限。接口失败直接显示错误，不生成替代动作。
- 取消会阻止写回与后续分段请求；已提交的服务端计算可能继续运行。

## 安装

下载并安装 [r15_kimodo.zip](dist/r15_kimodo.zip)，启用 **R15 Kimodo — Key Poses + Text**。Proscenium 也必须启用。

开发源文件位于 [r15_kimodo/](r15_kimodo/)。插件不修改 Proscenium 或 Roblox 导出器源码。

## 实现

`core.py`：基于骨骼方向、初始矩阵和角色朝向的双向映射；脊柱与颈部分段分配/合并。

`animation.py`：读取 Blender 5 Action slot/channelbag、按时间重采样 glTF、锚点残差校正、写回及实际求值验证。

`__init__.py`：面板、关键姿势记录、后台 HTTP 调用和 Action 切换。


## 1.1：原始数据可视化

主面板下的 **原始动画数据可视化** 可切换：关闭 / 叠加 / 并排。

- 显示服务器未经平滑、锁帧校正或 IK 调节的 SOMA30 动作。
- 保留全部原始采样点，并换算到场景帧号；不同源采样率使用子帧关键帧。
- 蓝色左侧、橙色右侧、黄色躯干；可显示所选 R15 对应源关节的绿色运动轨迹。
- 源骨架按角色朝向和腿长比例展示，保留 SOMA 自身身体比例；并排距离可调。
- 原始 JSON 响应嵌入 `.blend` 的 Text 数据块，重新打开不依赖外部文件或再次请求服务。
- 旧版示例可点 **导入已有接口数据**，选择之前的 `generation_evidence.json`。

## 1.1：骨骼调节 · IK / Reach

生成动画后，展开子面板并点击 **创建骨骼调节器**。人体布局按钮和下拉框可选择 15 个 R15 身体部位及 HumanoidRootPart。

每个骨骼具有以下整段动画参数：

| 参数 | 含义 |
| --- | --- |
| IK 强度 | 0 关闭骨骼链位置求解，1 完全追随目标；中间值按比例混合目标位置 |
| 旋转强度 | 0 使用原始关键姿势 Action 的局部旋转，1 使用生成旋转与目标旋转偏移 |
| 位移强度 | 原始与生成局部位移之间的混合权重，也控制 IK 位置跟随程度；四肢位置需配合 IK |
| 联动祖先数 | IK 允许向上联动的骨骼数；手脚默认两节，肘膝默认一节 |
| 目标位移/旋转 | 相对于该骨骼动画局部坐标系的偏移 |

点 **启用并选择 IK 目标**，IK 强度会设为 1；然后使用 Blender 的 G / R 拖动目标球。目标会随原始生成动作移动，你调整的是整段动作的相对偏移。修改滑条或移动目标后自动更新独立结果 Action，不需要重新调用模型。

- **锁定已 K 姿势** 默认开启；锚点附近使用默认 0.2 秒缓入缓出，防止调节在锚点旁突跳。当前处于锚点时，面板提示到中间帧预览。
- 关闭锁定后，调节也会作用于已 K 帧。
- **刷新并烘焙调节** 会重新读取原始/生成 Action，并将当前设置写成可直接导出的 Action。
- **移除调节器并恢复生成动作** 回到调节前的生成结果。
- 当前参数和目标偏移是整段设置，不能在 IK 目标上另外 K 动画；需要新增关键姿势时，使用主面板返回原始 R15 Action 编辑后重新生成。
- IK 保持骨骼长度，不拉伸骨架。目标超出所选骨骼链可达范围或多个目标互相冲突时，面板显示未达距离；可增加联动祖先数或移动目标。
- 调节范围是 R15 身体和角色根，面部/附件动画沿用原有 Action。

设计参考 Maya HumanIK 的 Reach Translation / Reach Rotation 与效应器操作方式。当前实现提供 FK 混合、骨骼链 CCD IK、旋转跟随、目标偏移与锚点保护；不包含 HumanIK 的全身平衡、Pull/Stiffness 或地面接触求解。

官方参考：[HumanIK Reach 属性](https://help.autodesk.com/cloudhelp/2026/CHS/Maya-CharacterAnimation/files/GUID-EB2A8BB0-801E-4251-8C4C-09986049CCBB.htm)。

`visualization.py`：原始响应嵌入、原生 SOMA 骨架与彩色骨骼连线、关节轨迹。

`controls.py`：FK Reach 混合、CCD 骨骼链 IK、目标拖动监听和调节结果烘焙。
